### 10.1.4 다층 퍼셉트론과 역전파

입력 층 - 은닉 층(하위 층 / 상위 층) - 출력 층

![image](https://github.com/user-attachments/assets/0f15432b-6bab-4624-bc97-b0241977367b)

심층 신경망(DNN): 은닉 층을 여러 개 쌓아 올린 인공 신경망 

후진 모드 자동 미분: 네트워크를 두 번만 통과(전진, 후진)하면 모든 단일 모델 파라미터에 대해 신경망 오차의 그레이디언트를 계산할 수 있는 알고리즘

역전파: 후진 모드 자동 미분 + 경사 하강법

에포크: 하나의 미니배치씩 진행하여 전체 훈련 세트를 처리하는 과정을 여러 번 반복하는 것

정방향 계산: 입력 층부터 출력 층까지 계산, 전달을 반복

1. 역전파 알고리즘이 먼저 미니배치에 대한 예측을 만들고(정방향 계산) 오차를 측정

2. 역방향으로 각 층을 거치면서 각 연결이 오차에 기여한 정도를 측정(역방향 계산)

### 10.1.5 회귀를 위한 다층 퍼셉트론

```python
from sklearn.datasets import fetch_california_housing
from sklearn.metrics import mean_squared_error
from sklearn.model_selection import train_test_split
from sklearn.neural_network import MLPRegressor
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

# 캘리포니아 주택 데이터 로드
housing = fetch_california_housing()

# 데이터셋을 훈련 세트와 테스트 세트로 분할
X_train_full, X_test, y_train_full, y_test = train_test_split(
    housing.data, housing.target, random_state=42
)

# 훈련 세트를 다시 훈련 세트와 검증 세트로 분할
X_train, X_valid, y_train, y_valid = train_test_split(
    X_train_full, y_train_full, random_state=42
)

# MLPRegressor 모델 생성
mlp_reg = MLPRegressor(hidden_layer_sizes=[50, 50, 50], random_state=42)

# 표준화와 MLP 모델을 포함한 파이프라인 생성
pipeline = make_pipeline(StandardScaler(), mlp_reg)

# 모델 훈련
pipeline.fit(X_train, y_train)

# 검증 데이터 예측
y_pred = pipeline.predict(X_valid)

# RMSE 계산
rmse = mean_squared_error(y_valid, y_pred, squared=False)  # 약 0.505
```

```python
import tensorflow as tf

# 데이터 정규화 레이어
normalization_layer = tf.keras.layers.Normalization()

# 은닉층 정의
hidden_layer1 = tf.keras.layers.Dense(30, activation="relu")  # 첫 번째 은닉층
hidden_layer2 = tf.keras.layers.Dense(30, activation="relu")  # 두 번째 은닉층

# 층 연결 및 출력층 정의
concat_layer = tf.keras.layers.Concatenate()  # 층 연결
output_layer = tf.keras.layers.Dense(1)  # 출력층

# 입력층 정의
input_ = tf.keras.layers.Input(shape=X_train.shape[1:])

# 네트워크 흐름 구성
normalized = normalization_layer(input_)  # 입력 데이터 정규화
hidden1 = hidden_layer1(normalized)  # 첫 번째 은닉층 적용
hidden2 = hidden_layer2(hidden1)  # 두 번째 은닉층 적용
concat = concat_layer([normalized, hidden2])  # 정규화된 입력과 은닉층 출력 연결
output = output_layer(concat)  # 출력층 적용

# 모델 생성
model = tf.keras.Model(inputs=[input_], outputs=[output])
```

### 10.2.4 서브클래싱 API로 동적 모델 만들기

```python
import tensorflow as tf

# Wide and Deep 모델을 정의하는 클래스
class WideAndDeepModel(tf.keras.Model):
    def __init__(self, units=30, activation="relu", **kwargs):
        super().__init__(**kwargs)  # 모델에 이름을 부여하기 위해 필요함
        self.norm_layer_wide = tf.keras.layers.Normalization()  # Wide 입력 정규화
        self.norm_layer_deep = tf.keras.layers.Normalization()  # Deep 입력 정규화
        self.hidden1 = tf.keras.layers.Dense(units, activation=activation)  # 첫 번째 은닉층
        self.hidden2 = tf.keras.layers.Dense(units, activation=activation)  # 두 번째 은닉층
        self.main_output = tf.keras.layers.Dense(1)  # 메인 출력층
        self.aux_output = tf.keras.layers.Dense(1)  # 보조 출력층

    def call(self, inputs):
        input_wide, input_deep = inputs  # 두 개의 입력을 분리
        norm_wide = self.norm_layer_wide(input_wide)  # Wide 입력 정규화
        norm_deep = self.norm_layer_deep(input_deep)  # Deep 입력 정규화
        hidden1 = self.hidden1(norm_deep)  # 첫 번째 은닉층 적용
        hidden2 = self.hidden2(hidden1)  # 두 번째 은닉층 적용
        concat = tf.keras.layers.concatenate([norm_wide, hidden2])  # Wide와 Deep 부분을 결합
        output = self.main_output(concat)  # 메인 출력
        aux_output = self.aux_output(hidden2)  # 보조 출력

        return output, aux_output

# 모델 생성
model = WideAndDeepModel(30, activation="relu", name="my_cool_model")
```

## 10.3 신경망 하이퍼파라미터 튜닝하기

```python
import keras_tuner as kt
import tensorflow as tf

# 모델 빌드 함수 정의
def build_model(hp):
    # 하이퍼파라미터 설정
    n_hidden = hp.Int("n_hidden", min_value=0, max_value=8, default=2)  # 은닉층 개수
    n_neurons = hp.Int("n_neurons", min_value=16, max_value=256)  # 뉴런 개수
    learning_rate = hp.Float("learning_rate", min_value=1e-4, max_value=1e-2, sampling="log")  # 학습률

    # 옵티마이저 선택
    optimizer = hp.Choice("optimizer", values=["sgd", "adam"])
    if optimizer == "sgd":
        optimizer = tf.keras.optimizers.SGD(learning_rate=learning_rate)
    else:
        optimizer = tf.keras.optimizers.Adam(learning_rate=learning_rate)

    # 모델 생성
    model = tf.keras.Sequential()
    model.add(tf.keras.layers.Flatten())  # 입력층

    # 은닉층 추가
    for _ in range(n_hidden):
        model.add(tf.keras.layers.Dense(n_neurons, activation="relu"))

    # 출력층 추가
    model.add(tf.keras.layers.Dense(10, activation="softmax"))

    # 모델 컴파일
    model.compile(
        loss="sparse_categorical_crossentropy",
        optimizer=optimizer,
        metrics=["accuracy"],
    )

    return model
```

### 10.3.1 은닉 층 개수

복잡한 문제의 경우 심층 신경망이 얕은 신경망보다 파라미터 효율성이 훨씬 좋음

아래쪽 은닉 층은 저수준의 구조를 모델링

중간 은닉 층은 저수준의 구조를 연결해 중간 수준의 구조를 모델링

가장 위쪽 은닉 층과 출력 층은 중간 수준의 구조를 연결해 고수준의 구조를 모델링

전이 학습: 저수준 구조를 학습할 필요 없이 고수준 구조만 학습하면 되게

새로운 신경망에서 처음 몇 개 층의 가중치와 편향을 난수로 초기화하는 대신 첫 번째 신경망의 층에 있는 가중치와 편향을 난수로 초기화하는 대신 첫 번째 신경망의 층에 있는 가중치와 편향 값으로 초기화

### 10.3.2 은닉 층의 뉴런 개수

입력 층과 출력 층의 누런 개수는 해당 작업에 필요한 입력과 출력의 형태에 따라 결정

층의 개수와 마찬가지로 네트워크가 과대적합이 시작되기 전까지 점진적으로 뉴런 수를 늘릴 수 있음
