# 14장 합성곱 신경망을 사용한 컴퓨터 비전

## 14.1 시각 피질 구조

1. 시각 피질이란?

시각 피질(Visual Cortex)은 뇌의 후두엽(Occipital Lobe)에 위치한 영역으로, 시각 정보를 처리하는 핵심 역할을 한다. 인간이 사물을 인식하는 과정에서 시각 피질은 원시적인 형태의 시각 신호를 받아 점점 더 복잡한 패턴으로 변환하는 계층적 구조를 가진다.

2. CNN과의 관계

컴퓨터 비전에서 사용되는 **합성곱 신경망(CNN, Convolutional Neural Networks)**은 시각 피질의 구조에서 영감을 받아 개발되었다.
CNN의 **합성곱 계층(Conv Layer)**이 V1처럼 기본적인 특징을 추출하고, 심층 계층이 V2~V5처럼 점점 복잡한 패턴을 학습하는 방식과 유사하다.

CNN 모델에서의 계층적 처리 과정:

초기 계층(Conv1, Conv2) → 엣지, 방향 감지 (V1과 유사)

중간 계층(Conv3, Conv4) → 형태 및 패턴 인식 (V2~V4와 유사)

깊은 계층(Conv5 이후) → 객체 및 움직임 인식 (V5와 유사)

## 14.2 합성곱 층

합성곱 층(Conv Layer)은 CNN(Convolutional Neural Networks)의 핵심 요소로, 이미지나 시계열 데이터를 처리할 때 중요한 역할을 한다.

이 층에서는 **필터(커널, Kernel)**를 이용해 입력 데이터에서 특징을 추출하고, **특성 맵(Feature Map)**을 생성한다.

### 14.2.1 필터

필터(커널, Kernel)는 합성곱 연산을 수행하는 작은 행렬(Matrix)로, 입력 이미지의 특정 패턴을 감지하는 역할을 한다.

필터 크기: 일반적으로 (3×3) 또는 (5×5) 크기의 행렬을 사용

스트라이드(Strides): 필터가 이동하는 간격

패딩(Padding): 경계 처리 방식 (VALID, SAME)

### 14.2.2 여러 가지 특성 맵 쌓기

특성 맵: 합성곱 연산을 수행한 결과로 얻어지는 행렬. 특정 패턴을 감지한 결과값이 담겨 있다.

### 14.2.3 케라스로 합성곱 층 구현하기

```python
import tensorflow as tf
from sklearn.datasets import load_sample_images

# 샘플 이미지 로드
images = load_sample_images()["images"]

# 이미지 전처리: 중심 자르기 및 정규화
images = tf.keras.layers.CenterCrop(height=70, width=120)(images)
images = tf.keras.layers.Rescaling(scale=1 / 255)(images)

# 이미지 크기 확인
print(images.shape)  # TensorShape([2, 70, 120, 3])

# 합성곱 층 적용 (패딩 없음)
conv_layer = tf.keras.layers.Conv2D(filters=32, kernel_size=7)
fmaps = conv_layer(images)

# 특성 맵 크기 확인
print(fmaps.shape)  # TensorShape([2, 64, 114, 32])

# 합성곱 층 적용 (패딩="same")
conv_layer = tf.keras.layers.Conv2D(filters=32, kernel_size=7, padding="same")
fmaps = conv_layer(images)

# 특성 맵 크기 확인
print(fmaps.shape)  # TensorShape([2, 70, 120, 32])

# 합성곱 층의 가중치 확인
kernels, biases = conv_layer.get_weights()
print(kernels.shape)  # (7, 7, 3, 32)
print(biases.shape)   # (32,)
```

### 14.2.4 메모리 요구 사항

CNN 모델을 학습할 때는 **많은 메모리(RAM & GPU 메모리)**가 필요하다.

메모리 사용량은 입력 크기, 필터 개수, 층의 개수 등에 따라 달라진다.

## 14.3 풀링 층

풀링(Pooling)은 CNN(Convolutional Neural Network)에서 특성 맵(Feature Map)의 크기를 줄이는 과정이다.

주요 목적은 연산량 감소, 과적합 방지, 공간적 불변성 유지이다.

1) 최대 풀링(Max Pooling)

가장 일반적인 풀링 기법

필터 크기 내에서 가장 큰 값을 선택

엣지, 형태 등의 중요한 특징을 보존하면서 크기를 줄일 수 있음

2) 평균 풀링(Average Pooling)

필터 내 픽셀 값의 평균을 계산하여 축소

세부 정보까지 보존하지만, 경계 정보가 흐려질 수 있음

주로 영상 인식보다는 음성 데이터 처리 등에 활용

3) 글로벌 풀링(Global Pooling)

전체 특성 맵에서 최댓값(Max) 또는 평균(Avg)을 하나의 값으로 축소

주로 Fully Connected Layer 직전에 사용됨

파라미터 수를 줄여 과적합을 방지하는 효과가 있음

## 14.4 케라스로 풀링 층 구현하기

```python
import tensorflow as tf

# 최대 풀링 레이어
max_pool = tf.keras.layers.MaxPool2D(pool_size=2)

# 깊이 방향 풀링 커스텀 레이어
class DepthPool(tf.keras.layers.Layer):
    def __init__(self, pool_size=2, **kwargs):
        super().__init__(**kwargs)
        self.pool_size = pool_size

    def call(self, inputs):
        shape = tf.shape(inputs)  # 입력 텐서의 모양 확인
        groups = shape[-1] // self.pool_size  # 채널 그룹 수
        new_shape = tf.concat([shape[:-1], [groups, self.pool_size]], axis=0)
        return tf.reduce_max(tf.reshape(inputs, new_shape), axis=-1)  # 그룹 내 최대값 반환

# 전역 평균 풀링 레이어
global_avg_pool = tf.keras.layers.GlobalAvgPool2D()

# Lambda 층을 이용한 전역 평균 풀링과 동일한 기능 수행
global_avg_pool_lambda = tf.keras.layers.Lambda(lambda X: tf.reduce_mean(X, axis=[1, 2]))

# 입력 이미지 적용 예시
images = tf.random.normal([2, 70, 120, 3])  # 예제 이미지 생성 (2개, 높이 70, 너비 120, 채널 3)
output = global_avg_pool(images)

print(output.numpy())  # 결과 출력
```

### 14.5.1 LeNet-5

LeNet-5는 최초의 CNN 모델로, 손글씨 숫자 인식(MNIST) 작업을 위해 개발되었다.

CNN의 기본적인 합성곱(Conv) → 풀링(Pooling) → Fully Connected(FC) 구조를 제시

당시에는 혁신적이었지만, 현재는 성능이 낮아 잘 사용되지 않음

### 14.5.2 AlexNet

AlexNet은 CNN이 대규모 데이터셋(ImageNet)에서도 강력한 성능을 낼 수 있음을 증명한 모델이다.

ReLU 활성화 함수 도입 → 학습 속도 향상

Dropout 사용 → 과적합 방지

GPU 병렬 연산 활용 → 연산 속도 개선

현재는 더 발전된 모델이 많아 잘 사용되지 않지만, CNN 연구에 큰 영향을 줌

### 14.5.3 GoogLeNet

GoogleNet은 병렬 합성곱 연산(Inception Module) 구조를 도입하여 성능을 크게 향상시켰다.

Inception Module 사용 → 연산량 감소 + 다양한 특징 추출 가능

Global Average Pooling 도입 → 과적합 방지

연산량 최적화 → AlexNet보다 적은 파라미터 수로 더 뛰어난 성능 달성

### 14.5.4 VGGNet

VGGNet은 작은 필터(3×3)를 깊게 쌓아서 성능을 개선한 CNN 모델이다.

모델이 깊을수록 성능 향상

연산량이 많고 메모리 사용량이 높음 → 실용성이 떨어짐 (무겁지만 강력)

현재는 ResNet, MobileNet 등 경량화된 모델이 더 많이 사용됨

### 14.5.5 ResNet

ResNet은 **잔차 연결(Skip Connection)**을 도입하여 깊은 네트워크에서도 학습이 가능하도록 한 모델이다.

Gradient Vanishing 문제 해결 → 딥러닝 모델이 매우 깊어질 수 있도록 만듦

ResNet-50 이상 모델은 현재도 널리 사용됨

### 14.5.6 Xception

Xception은 Inception 구조를 개선한 모델로, 연산량을 줄이고 성능을 높이는 Depthwise Separable Convolution을 사용한다.

Depthwise Separable Convolution → 연산량 감소

MobileNet에도 활용됨

### 14.5.7 SENet

SENet은 채널 간 관계를 학습하여 중요한 특징을 더 강조하는 구조이다.

Attention Mechanism 적용 → 중요한 특징 강화

ResNet과 결합해 ResNeXt, SE-ResNet 같은 모델로 확장 가능

## 14.6 케라스로 ResNet-34 CNN 구현하기

```python
from functools import partial
import tensorflow as tf

# 기본 Convolution 레이어 설정
DefaultConv2D = partial(tf.keras.layers.Conv2D, kernel_size=3, strides=1, 
                        padding="same", kernel_initializer="he_normal")

# ResNet의 기본 Residual Unit 정의
class ResidualUnit(tf.keras.layers.Layer):
    def __init__(self, filters, strides=1, activation="relu", **kwargs):
        super().__init__(**kwargs)
        self.activation = tf.keras.activations.get(activation)

        # 주요 레이어 구성
        self.main_layers = [
            DefaultConv2D(filters, strides=strides),
            tf.keras.layers.BatchNormalization(),
            self.activation,
            DefaultConv2D(filters),
            tf.keras.layers.BatchNormalization()
        ]

        # 스킵 레이어 (stride가 1보다 크면 추가 적용)
        self.skip_layers = []
        if strides > 1:
            self.skip_layers = [
                DefaultConv2D(filters, kernel_size=1, strides=strides),
                tf.keras.layers.BatchNormalization()
            ]

    def call(self, inputs):
        Z = inputs
        for layer in self.main_layers:
            Z = layer(Z)

        skip_Z = inputs
        for layer in self.skip_layers:
            skip_Z = layer(skip_Z)

        return self.activation(Z + skip_Z)

# 모델 정의
model = tf.keras.Sequential([
    DefaultConv2D(64, kernel_size=7, strides=2, input_shape=[224, 224, 3]),
    tf.keras.layers.BatchNormalization(),
    tf.keras.layers.Activation("relu"),
    tf.keras.layers.MaxPool2D(pool_size=3, strides=2, padding="same"),
])

# ResNet 블록 추가
prev_filters = 64
for filters in [64] * 3 + [128] * 4 + [256] * 6 + [512] * 3:
    strides = 1 if filters == prev_filters else 2
    model.add(ResidualUnit(filters, strides=strides))
    prev_filters = filters

# 분류 레이어 추가
model.add(tf.keras.layers.GlobalAvgPool2D())
model.add(tf.keras.layers.Flatten())
model.add(tf.keras.layers.Dense(10, activation="softmax"))

# 모델 요약 출력
model.summary()
```

```python
import tensorflow as tf
from sklearn.datasets import load_sample_images

# ResNet50 모델 불러오기 (사전 훈련된 가중치 사용)
model = tf.keras.applications.resnet50.ResNet50(weights="imagenet")

Y_proba = model.predict(inputs)

top_K = tf.keras.applications.resnet50.decode_predictions(Y_proba, top=3)

# 예측된 상위 3개 클래스 출력
for image_index in range(len(images)):
    print(f"Image #{image_index}")
    for class_id, name, y_proba in top_K[image_index]:

```

## 14.8 사전 훈련된 모델을 사용한 전이 학습

```python
import tensorflow_datasets as tfds
import tensorflow as tf

# 데이터셋 로드 및 정보 확인
dataset, info = tfds.load("tf_flowers", as_supervised=True, with_info=True)
dataset_size = info.splits["train"].num_examples  # 데이터 개수
class_names = info.features["label"].names  # 클래스 이름
n_classes = info.features["label"].num_classes  # 클래스 개수

# 데이터셋 분할
test_set_raw, valid_set_raw, train_set_raw = tfds.load(
    "tf_flowers",
    split=["train[:10%]", "train[10%:25%]", "train[25%:]"],
    as_supervised=True
)

# 이미지 전처리 및 크기 조정
batch_size = 32
preprocess = tf.keras.Sequential([
    tf.keras.layers.Resizing(height=224, width=224, crop_to_aspect_ratio=True),
    tf.keras.layers.Lambda(tf.keras.applications.xception.preprocess_input)
])

# 데이터셋 매핑 및 배치 구성
train_set = train_set_raw.map(lambda X, y: (preprocess(X), y))
train_set = train_set.shuffle(1000, seed=42).batch(batch_size).prefetch(1)
valid_set = valid_set_raw.map(lambda X, y: (preprocess(X), y)).batch(batch_size)
test_set = test_set_raw.map(lambda X, y: (preprocess(X), y)).batch(batch_size)

# 데이터 증강
data_augmentation = tf.keras.Sequential([
    tf.keras.layers.RandomFlip(mode="horizontal", seed=42),
    tf.keras.layers.RandomRotation(factor=0.05, seed=42),
    tf.keras.layers.RandomContrast(factor=0.2, seed=42),
])

# 사전 훈련된 모델 로드 및 수정
base_model = tf.keras.applications.xception.Xception(weights="imagenet", include_top=False)
avg = tf.keras.layers.GlobalAveragePooling2D()(base_model.output)
output = tf.keras.layers.Dense(n_classes, activation="softmax")(avg)
model = tf.keras.Model(inputs=base_model.input, outputs=output)

# 사전 훈련된 가중치 동결
for layer in base_model.layers:
    layer.trainable = False

# 모델 컴파일 및 훈련
optimizer = tf.keras.optimizers.SGD(learning_rate=0.1, momentum=0.9)
model.compile(loss="sparse_categorical_crossentropy", optimizer=optimizer, metrics=["accuracy"])
history = model.fit(train_set, validation_data=valid_set, epochs=3)

# 특정 층부터 훈련 가능하게 변경
for layer in base_model.layers[56:]:
    layer.trainable = True

# 모델 재컴파일 및 추가 훈련
optimizer = tf.keras.optimizers.SGD(learning_rate=0.01, momentum=0.9)
model.compile(loss="sparse_categorical_crossentropy", optimizer=optimizer, metrics=["accuracy"])
history = model.fit(train_set, validation_data=valid_set, epochs=10)
```

## 14.10 객체 탐지

객체 탐지(Object Detection)는 이미지 내에서 여러 개의 객체를 찾아 위치(Bounding Box)와 클래스(Class)를 동시에 예측하는 문제이다.

이전의 분류(Classification) 와 위치 추정(Localization) 은 하나의 객체만 찾았지만,
객체 탐지는 여러 개의 객체를 동시에 감지하는 것이 핵심이다.

객체가 있는 위치 (Bounding Box: x, y, width, height) 예측

각 객체의 클래스(Class) 예측

### 14.10.1 완전 합성곱 신경망

완전 합성곱 신경망(FCN)은 전통적인 Fully Connected(FC) 층을 사용하지 않고, 전부 Conv Layer로만 구성된 신경망이다.

이는 픽셀 단위의 위치 정보가 중요한 객체 탐지 및 세그멘테이션에 매우 적합하다.

입력 크기에 제한이 없음 (Fully Connected 층 없음)

CNN을 통해 이미지의 위치 정보 유지

주로 객체 탐지 및 이미지 세그멘테이션에 사용됨

### 14.10.2 YOLO

YOLO(You Only Look Once)는 이미지를 한 번만 살펴서 객체를 탐지하는 실시간 객체 탐지 모델이다.

이미지를 한 번만 CNN에 통과시켜 모든 객체를 탐지

속도가 매우 빠름 (YOLOv8 기준, 30~60 FPS)

실시간 객체 탐지 및 자율주행, 영상 처리에 사용됨

## 14.11 객체 추적

**객체 추적(Object Tracking)**은 비디오 또는 실시간 영상에서 특정 객체를 지속적으로 추적하는 기술이다.

객체 탐지(Object Detection)와 달리, 한 번 탐지한 객체를 프레임 간 이동하면서 지속적으로 추적하는 것이 핵심이다.

CSRT (Channel and Spatial Reliability Tracking) → 정확도 높음, 속도 느림

KCF (Kernelized Correlation Filters) → 속도 빠름, 단순한 객체에 적합

MOSSE (Minimum Output Sum of Squared Error) → 가장 빠름, 정밀도 낮음

## 14.12 시맨틱 분할

**시맨틱 분할(Semantic Segmentation)**은 이미지의 각 픽셀을 특정 클래스에 할당하는 기술이다.

즉, 객체 단위가 아니라 픽셀 단위로 분류하는 것이 특징이다.

이 기술은 자율주행, 의료 영상 분석, 위성 이미지 처리 등에 활용된다.
