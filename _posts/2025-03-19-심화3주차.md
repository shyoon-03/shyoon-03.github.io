## 15.3 시계열 예측하기

시계열: 일반적으로 일정한 간격의 타임 스텝별 값을 가진 데이터

단변량 시계열: 타임 스텝마다 하나의 값이 있을 경우

다변량 시계열: 타임 스텝마다 여러 개의 값이 있을 경우

OO 계절성: OO마다 비슷한 패턴이 반복

단순 예측: 계절성을 통해서 예측

차분: 두 시계열의 차이를 뺀 것

자기상관 시계열: 시계열이 시간이 지연된 자기자신과 상관관계를 가질 경우

정상 시계열: 계절성이나 트렌드가 없어 시간에 따라 통계적 속성이 일정한 경우

평균 절댓값 오차(MAE)

평균 절대 비율 오차(MAPE): MAE를 타깃값으로 나눈 값

### 15.4.1 불안정한 그레이디언트 문제와 싸우기

심층 신경망에 사용했던 많은 기법을 RNN에서도 사용 가능하지만, 수렴하지 않는 활성화 함수는 큰 도움이 되지 않음

배치 정규화는 RNN에서 효율적으로 사용 x

메모리 셀에 배치 정규화 층을 추가하여 타임 스텝마다 적용

-> 은닉 상태가 아닌 층의 입력에 적용했을 때만 조금 도움 됨

층 정규화는 RNN에 잘 맞음

배치 정규화와 매우 비슷하지만, 배치 차원에 대해 정규화하는 대신 특성 차원에 대해 정규화

```python
import tensorflow as tf

# 사용자 정의 RNN 셀 (Layer Normalization 포함)
class LNSimpleRNNCell(tf.keras.layers.Layer):
    def __init__(self, units, activation="tanh", **kwargs):
        super().__init__(**kwargs)
        self.state_size = units  # 상태 크기 설정
        self.output_size = units  # 출력 크기 설정
        self.simple_rnn_cell = tf.keras.layers.SimpleRNNCell(units, activation=None)
        self.layer_norm = tf.keras.layers.LayerNormalization()  # Layer Normalization 추가
        self.activation = tf.keras.activations.get(activation)  # 활성화 함수 설정

    def call(self, inputs, states):
        outputs, new_states = self.simple_rnn_cell(inputs, states)
        norm_outputs = self.activation(self.layer_norm(outputs))  # 정규화 후 활성화 적용
        return norm_outputs, [norm_outputs]  # 출력 및 상태 반환

# 모델 정의 (RNN 포함)
custom_ln_model = tf.keras.Sequential([
    tf.keras.layers.RNN(LNSimpleRNNCell(32), return_sequences=True, input_shape=[None, 5]),
    tf.keras.layers.Dense(14)  # 최종 출력층
])
```

#### 1D 합성곱 층으로 시퀀스 처리하기

LSTM과 GRU 셀이 단순한 RNN보다 훨씬 긴 시퀀스를 다룰 수 있지만 매우 제한적인 단기 기억을 가져 100 타임 스텝 이상의 시퀀스에서 장기 패턴을 학습하는 데의 어려움을 해결

시퀀스 전체에 대해 몇 개의 커널을 슬라이딩하여 커널마다 1D 특성 맵을 출력

이 때 각 커널은 매우 짧은 하나의 순차 패턴을 감지하도록 학습됨

#### WaveNet

이 네트워크는 층마다 팽창 비율을 두 배로 늘리는 1D 합성곱 층을 쌓음

팽창 비율을 두 배로 늘린 덕분에 네트우크는 아주 긴 시퀀스를 매우 효율적으로 처리 가능
![image](https://github.com/user-attachments/assets/ff3ae0f8-fc59-4004-854e-8356c58495d1)

```python
import tensorflow as tf

# Wavenet 모델 생성
wavenet_model = tf.keras.Sequential()

# 입력층 추가
wavenet_model.add(tf.keras.layers.Input(shape=[None, 5]))

# Dilated Causal Convolution 계층 추가
for rate in (1, 2, 4, 8) * 2:
    wavenet_model.add(tf.keras.layers.Conv1D(
        filters=32, kernel_size=2, padding="causal",
        activation="relu", dilation_rate=rate
    ))

# 최종 출력층
wavenet_model.add(tf.keras.layers.Conv1D(filters=14, kernel_size=1))
```
